# Práctica Acumulativa RA1 - Jukebox PHP

Aplicación web desarrollada en PHP para la gestión de un catálogo musical y reproductor multimedia containerizado mediante Docker.

## 🚀 Requisitos e Instalación

### Requisitos previos
- Docker Desktop instalado y en ejecución.
- Git.

### Despliegue del entorno

1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/Checa2004/ACTPHP_PracticaAcumulativaDePHP.git](https://github.com/Checa2004/ACTPHP_PracticaAcumulativaDePHP.git)
   cd ACTPHP_PracticaAcumulativaDePHP
